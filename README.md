# SpamhausBlocker

**SpamhausBlocker — это скрипт, который автоматически настраивает брандмауэр для блокировки исходящего трафика к подсетям из списка Spamhaus (угнанные и выделенные спамерам/киберпреступникам сети).**

# Использование

**`bash <(curl -Ls https://raw.githubusercontent.com/sngvy/SpamhausBlocker/refs/heads/main/SpamhausBlocker.sh)`**
